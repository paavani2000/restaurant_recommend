## 🍽️ Decentralized Restaurant Recommendation System  
An intelligent, ML-driven recommendation system enhanced with blockchain technology to ensure personalized suggestions and transparent review incentives, fostering trust and engagement.

## 📌 Overview  
The system combines collaborative filtering and sentiment analysis to recommend restaurants tailored to user preferences. Reviews and loyalty point rewards are managed using Solidity smart contracts for transparency and fairness.

## 🚀 Features  
🧠 Personalized Recommendations: Cosine similarity & matrix factorization for tailored results  
💬 Sentiment Insights: NLP-based sentiment analysis to weigh reviews qualitatively  
🔗 Transparent Incentives: Smart contracts reward users for authentic reviews with loyalty points  
🛡️ Data Trust & Integrity: Blockchain ensures tamper-proof review tracking

## 🧰 Tech Stack  
Python – Machine learning and API backend  
Scikit-learn, VADER – Recommendation and sentiment analysis  
Solidity, Ethereum Testnet – Smart contract development  
Web3.py, Ganache – Blockchain interaction and testing  
Flask – Lightweight API layer
