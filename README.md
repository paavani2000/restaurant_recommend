📸 Decentralized Restaurant Recommendation System
A personalized, ML-powered recommendation platform that leverages big data, sentiment analysis, and blockchain to suggest restaurants based on user history and Yelp data. Smart contracts ensure transparency and reward authentic reviews.

📌 Overview
The system combines collaborative filtering, sentiment analysis, and user history to recommend restaurants tailored to individual preferences. Yelp API powers real-world data enrichment, while Solidity smart contracts manage loyalty-based review rewards to ensure fairness and transparency.

🚀 Features
🧠 Personalized Recommendations: Collaborative filtering with cosine similarity and matrix factorization on user history
💬 Sentiment Insights: NLP-based sentiment analysis to weigh reviews qualitatively
🔗 Transparent Incentives: Smart contracts reward users for authentic reviews using loyalty points
🛡️ Data Trust & Integrity: Blockchain ensures tamper-proof review tracking
📊 Big Data Integration: Scalable ingestion and analysis of Yelp and user-generated review data

🛠️ Tech Stack
Python – ML modeling and backend logic

Scikit-learn, VADER – Recommendation algorithms and sentiment analysis

Solidity, Ethereum Testnet – Smart contract development

Web3.py, Ganache – Blockchain integration and testing

Flask – REST API layer

Yelp API – Restaurant metadata and reviews
